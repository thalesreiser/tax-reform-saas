# Apps

Each app is created by its own task, so this folder starts empty.

| Folder           | App                                                     | Task     |
| ---------------- | ------------------------------------------------------- | -------- |
| `apps/api`       | Fastify API (internal and public `/v1`)                 | BE-01.1  |
| `apps/web`       | Nuxt 4 dashboard, simulator, share view and landing     | FE-01.1  |
| `apps/extension` | WXT browser extension for the Emissor Nacional da NFS-e | EXT-01.2 |

Planned packages: `packages/engine-client` (MOT-01.3) and `packages/simulation` (MOT-03.2).
